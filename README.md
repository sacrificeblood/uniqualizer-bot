# 🤖 Telegram Image Uniqualizer Bot

Бот принимает фото → создаёт **6 уникальных версий** → отправляет обратно альбомом.

---

## 📋 Методы уникализации

| # | Метод | Что делает |
|---|-------|-----------|
| 1 | 🔆 Яркость/контраст | Случайная коррекция яркости, контраста, резкости |
| 2 | 🎨 Цветовой сдвиг | Сдвиг насыщенности + тёплый/холодный оттенок |
| 3 | 🔄 Поворот + кроп | Лёгкий поворот ±1.5° + обрезка краёв + ресайз |
| 4 | 🪞 Зеркало + цвет | Горизонтальный флип + цветокоррекция |
| 5 | ✨ Шум + шарп | Лёгкое размытие/смягчение + повышение резкости |
| 6 | ✂️ Кроп + ресайз | Асимметричный кроп 1–3% + ресайз + насыщенность |

## 🚀 Быстрый запуск

### 1. Получить токен бота
1. Напиши [@BotFather](https://t.me/BotFather) в Telegram
2. `/newbot` → дай имя → получи токен вида `123456:ABC-DEF...`

### 2. Установить зависимости
```bash
pip install -r requirements.txt
```

### 3. Запустить (вариант 1 — через переменную окружения)
```bash
export BOT_TOKEN="123456:ABC-DEF..."
python bot.py
```

### 3. Запустить (вариант 2 — вписать токен в код)
Открой `bot.py`, найди строку:
```python
TOKEN = os.getenv("BOT_TOKEN", "YOUR_BOT_TOKEN_HERE")
```
Замени `YOUR_BOT_TOKEN_HERE` на свой токен.

## 🐳 Запуск через Docker (опционально)

```dockerfile
FROM python:3.11-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY bot.py .
ENV BOT_TOKEN=""
CMD ["python", "bot.py"]
```

```bash
docker build -t uniqualizer-bot .
docker run -d -e BOT_TOKEN="твой_токен" uniqualizer-bot
```
